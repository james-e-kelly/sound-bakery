Detailed Description

Base object that all sound Bakery objects should inherit from.

Objects can own other objects.

Todo:
Remove the object class. There should be a greater split between data and runtime. The object class only exists to give a base class to runtime objects. However, all runtime objects should be small structs in a single array - not full objects with reflection.
