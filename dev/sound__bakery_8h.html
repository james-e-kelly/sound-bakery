sbk_status SB_API sbk_log ( ma_log_level  level,
const char *  message 
)

Log a message to Sound Bakery.

There is no guarantee the message will reach a specific output, like the console or a file. It is possible in some configurations that the message will not go anywhere. The log destination all depends on the @r sbk_system_config options and how the user handles messages received in the logging callback.

Parameters
levelof the message, from MA_LOG_LEVEL_DEBUG to MA_LOG_LEVEL_ERROR. Use MA_LOG_LEVEL_INFO for regular messages
messageto log
Returns
SBK_SUCCESS on successful logging
SBK_ERR_INVALID_PARAMETER if the message is null
SBK_ERR_BAKERY_UNINITIALIZED if the system object does not exist or is not initialized

◆ sbk_system_get_object_info()

SBK_NODISCARD sbk_status SB_API sbk_system_get_object_info ( uint64_t  index,
sbk_id *  id,
char *  name,
uint64_t  nameSize,
uint64_t *  actualNameSize 
)

Get the ID and name of the database object at the index.

The information from this function can help to start generating assets inside an engine. The name can be used to create assets. The name contains both the type, path, and name of the object. The asset can be saved with the ID. That ID can then be used in functions like @sbk_system_post_event.

Parameters
indexthe index of the object to get information about. Should not exceed the count retrieved from @r sbk_system_get_object_count
idthe ID of the object at the index
namethe name of the object at the index. Will be in the form of "type:path/name"
nameSizesize of the buffer allocated for @r name. Should be allocated by the user
actualNameSizethe actual size of the name from the database
Returns
SBK_SUCCESS if the object was found and id and name set
SBK_ERR_BAKERY_OBJECT_NOT_FOUND if the object was not found
